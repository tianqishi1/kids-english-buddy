# 英语小伴 Kids English Buddy v0.1

面向 3–12 岁儿童的游戏化英语口语学伴（方向① MVP 初始可用版）。
**纯本地静态网页应用：无后端、无账号、无域名、无备案要求**，浏览器打开即用。

## 快速开始

```powershell
cd D:\codex\kids-english-buddy
python -m http.server 8321 --bind 127.0.0.1
```

然后用 **电脑 Chrome 或 Edge** 打开 <http://localhost:8321>

> 语音识别（Web Speech API）要求安全上下文（localhost 或 https）+ Chrome/Edge 内核。
> **中国大陆网络强烈建议用 Edge**：Chrome 的识别走 Google 服务，常报 network 错误；Edge 走微软服务可正常识别。
> v0.1.1 起识别失败不再卡关：可「跳过这关」、一键切换跟读模式，识别中实时显示听到的文字。
> 手机直接访问局域网 http 地址时麦克风不可用，会自动降级为「跟读练习模式」（可听可练，无自动评分）。
> 首次使用请允许麦克风权限。

## 已实现功能（v0.1）

- **IP 学伴 Pip**：SVG 小狐狸，四阶段养成（神秘蛋→小小Pip→活力Pip→超级Pip），靠 XP 升级
- **分龄课程**：3–6 启蒙 / 6–9 基础 / 9–12 提升，共 9 门场景课 45 个对话回合（打招呼/颜色/动物/家人/点餐/书包/爱好/天气/问路）
- **语音闭环**：Pip 说（TTS 儿童语速）→ 孩子点麦克风说（STT）→ 关键词覆盖+置信度评分 → 星星/逐词反馈 → 鼓励语音
- **游戏化**：每回合星星、XP、宠物升级动画、连续打卡天数（streak）
- **间隔重复复习**：答错的词明天到期、答对的 3 天后到期，首页「今日复习」入口
- **家长中心**（算术题家长门防儿童误入）：今日/本周开口时长、7 天柱状图、掌握词句数、平均匹配度、课程设置（昵称/年龄段/每日时长上限）、数据导出/导入/清空
- **每日时长锁**：达到上限温柔劝退，家长可通过家长门临时解锁
- **晒娃分享卡**：Canvas 生成 720×960 成绩卡片 PNG，一键保存（获客素材内建）
- **合规内建**：封闭课程域（无开放式 AI 生成）、无广告、数据仅存本机 localStorage、购买/设置需家长门
- **降级策略**：无 STT 环境自动切换跟读练习模式，任何设备可用

## 已知限制（v0.1）

1. 语音识别依赖浏览器 Web Speech API（Chrome 走 Google 服务），**非儿童优化 ASR**，童声识别率有限——正式版需替换为合规儿童语音评测 API（见技术方案 v0.2）
2. 评分为关键词覆盖度，非音素级发音评测
3. 数据仅存本机浏览器，换设备需手动导出/导入
4. 手机局域网 http 访问无麦克风权限（需 https，公网上线后解决）
5. 课程仅 9 门，需持续教研扩充
